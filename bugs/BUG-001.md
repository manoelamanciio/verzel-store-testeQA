# BUG-001: API cobra frete incorretamente para compras com subtotal exato de R$ 200,00 (CA08)

## Descrição
Ao calcular o carrinho com itens cujo subtotal atinge exatamente o valor limite de R$ 200,00 (ex: 2x Mochila Urbana 20L a R$ 100,00 cada), a API retorna `freteGratis: false` e cobra a taxa de frete de R$ 19,90. Além disso, a resposta apresenta uma contradição interna ao indicar `valorFaltanteFreteGratis: 0` juntamente com a cobrança do frete.

## Endpoint Impactado
`POST /api/carrinho/calcular`

## Passos para Reproduzir
1. Enviar uma requisição POST para `/api/carrinho/calcular` com o seguinte payload:
```json
{
  "itens": [
    { "produtoId": "P005", "quantidade": 2 }
  ]
}

 ------

# Observar a resposta da API.

Comportamento Esperado
De acordo com o Critério de Aceite CA08, compras a partir de R$ 200,00 devem ter frete grátis (freteGratis: true, frete: 0).

Comportamento Atual
A API aceita a requisição, porém retorna:

{
  "subtotal": 200,
  "frete": 19.9,
  "freteGratis": false,
  "valorFaltanteFreteGratis": 0,
  "total": 219.9
}
