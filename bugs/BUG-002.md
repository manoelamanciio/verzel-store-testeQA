# BUG-002: API de cálculo do carrinho não valida o limite máximo de 5 unidades por produto (CA10)

## Descrição
Ao realizar a requisição de cálculo do carrinho via API informando 6 ou mais unidades de um mesmo produto, o sistema aceita o cálculo e retorna status `200 OK`, ignorando a regra de negócio da quantidade máxima permitida por item.

## Endpoint Impactado
`POST /api/carrinho/calcular`

## Passos para Reproduzir
1. Enviar uma requisição POST para `/api/carrinho/calcular` com quantidade superior a 5 para um produto:
```json
{
  "itens": [
    { "produtoId": "P001", "quantidade": 6 }
  ]
}
1. Analisar o código HTTP e o corpo da resposta


## Comportamento Esperado
A API deveria recusar a solicitação com código de status HTTP 422 Unprocessable Entity e mensagem de erro QUANTIDADE_MAXIMA_EXCEDIDA referente ao campo itens[0].quantidade.

Comportamento Atual
A API calcula o valor normalmente e retorna HTTP 200 OK.
