# BUG-003: Endpoint de criação de pedidos permite a criação de pedidos com quantidade de itens acima do limite (CA10)

## Descrição
A rota de criação de pedidos aceita solicitações contendo 6 ou mais unidades de um único produto, criando o pedido no banco de dados com status `201 Created` sem validar o limite estabelecido no CA10.

## Endpoint Impactado
`POST /api/pedidos`

## Passos para Reproduzir
1. Enviar uma requisição POST para `/api/pedidos` com o payload:
```json
{
  "itens": [
    { "produtoId": "P001", "quantidade": 6 }
  ]
}
1. Verificar resposta do servidor

## Comportamento Esperado
A API deve rejeitar o pedido com status 422 Unprocessable Entity e erro QUANTIDADE_MAXIMA_EXCEDIDA.

Comportamento Atual
O pedido é gerado com sucesso, retornando status 201 Created e número de pedido válido (ex: VZ-201540 com total de 359.40 para 6 unidades do produto P001).
